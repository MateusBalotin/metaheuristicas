Trabalho — Questão 1: Busca Tabu para a Mochila com Compartimentos

n=20 itens · P_TOTAL=510 · k=3 compartimentos (P₁=240, P₂=190, P₃=170) · solução inicial vazia · UFPR MNE 740

▸ Modelagem: variáveis, função de avaliação e penalidades
Variáveis: vetor a = (a₁, ..., a₂₀), com aⱼ ∈ {0, 1, 2, 3}
  aⱼ = 0 → item j fora da mochila · aⱼ = i → item j no compartimento i
  (equivale à matriz binária z: zij = 1 ⇔ aⱼ = i; a codificação por vetor garante Σᵢ zij ≤ 1)

Função de avaliação (com penalidades):
  f(a) = Σⱼ vⱼ·[aⱼ>0] − μ·( Σᵢ max(0, wᵢ − Pᵢ) + max(0, W − P_TOTAL) )
  wᵢ = peso do compartimento i · W = Σᵢ wᵢ · μ = 1 > max(vⱼ/pⱼ) = 8/14, logo violar capacidade nunca compensa

Busca Tabu:
  1. S₁ = solução vazia
  2. Vizinhança: alterar aⱼ de um item (inserir, remover ou mover entre compartimentos)
  3. Escolher movimento de maior f não-tabu, OU tabu com f > f(S*) (aspiração)
  4. Atributo tabu: item j alterado, tenure k=3 · decrementar os demais a cada iteração
  5. Erro ao final de cada iteração: erro = FO* − FO, com FO* = 99 (ótimo validado por solver exato)
